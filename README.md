# Pendientes

Lista de tareas simple en https://pendientes.taller.ink. Sin cuenta ni servidor: todo se guarda en el
navegador (localStorage), así que cada navegador tiene su propia lista.

- Agregar, marcar como hecha, editar (toca el texto), borrar con «Deshacer», filtrar.
- Fecha límite opcional (las vencidas se marcan en rojo).
- Reordenar arrastrando del asa (dedo o mouse) o con las flechas del teclado.

HTML, CSS y JS sin build. Letra Barlow (OFL), servida desde este repo.
